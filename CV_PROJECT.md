# CV-ready project entry

## English

**HCMC AI Challenge 2026 — Multimodal Video Retrieval System**  
*Python, FAISS, Elasticsearch, FastAPI, React, PyTorch*

- Built a multimodal video-retrieval system for KIS, QA, and TRAKE tasks, combining FAISS vector search with Elasticsearch metadata retrieval and OCR, ASR, and object-aware reranking.
- Built GPU-accelerated Kaggle preprocessing notebooks for quality-aware keyframe extraction, keyframe embedding generation, OCR, ASR transcription, and YOLO-based object detection.
- Developed a FastAPI backend with validated search APIs, asynchronous result/thumbnail handling, sidecar caching, neighbor-frame inspection, and CSV submission generation.
- Implemented a React dashboard and reproducible indexing/search utilities, with unit tests for retrieval, metadata alignment, artifact validation, and result processing.

## Short version

Built a multimodal video-search platform using FAISS, Elasticsearch, FastAPI, React, and PyTorch, supporting KIS/QA/TRAKE retrieval, OCR/ASR/object reranking, neighbor-frame inspection, and submission generation.
